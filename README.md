# KIRSH HOME Mix & Match

100 transparent PNG product images, numbered `001.png` through `100.png`, stored in the [`001~100`](001~100/) folder.

- Resolution: 1200 × 1600 px (3:4)
- Format: RGBA PNG with transparent background
- Composition: fixed `camera_sample` view and consistent lighting
- Order: left to right across each row, then the next row in the +Y direction

Each image contains one complete bed. The showroom floor and neighboring objects are excluded.

[Download all files as ZIP](https://github.com/ezenacademy0/AD/archive/refs/heads/main.zip)

`manifest.csv` lists each image's source combination, grid position, file size and hashes.
`SHA256SUMS` provides checksums for the 100 PNGs.

All images were checked for PNG integrity, 1200 × 1600 RGBA output, transparency, complete framing and distinct image content.

## Additional front view: camera_sample2

75 of 100 additional transparent PNGs are available in the [`camera_sample2`](camera_sample2/) folder, numbered `001.png` through `075.png`.

These images use the fixed `camera_sample2` front view, with the same 1200 × 1600 RGBA format, consistent lighting and combination order.
